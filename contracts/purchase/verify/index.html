Check a GYOTAK purchase

Enter a purchase ID — as text such as PB-YYYYMMDD-xxxxxxxx, or as 64 hexadecimal characters — to see what GYOTAK's purchase contract on Midnight mainnet has recorded for it. This page only reads the record; it changes nothing.

By default, this page gets the record through GYOTAK's server. The calculation and the check are done in your browser.

Optional: read the record directly with your own Blockfrost project ID

If you would rather not rely on GYOTAK's server, enter a Blockfrost project ID for Midnight mainnet. Blockfrost is a service that gives access to Midnight's public records; you can create a project ID at blockfrost.io. With a project ID, your browser asks Blockfrost for the record directly and GYOTAK's server is not used. The project ID is sent only to Blockfrost. This page does not save it and does not show it. Leave it empty to read through GYOTAK's server.
